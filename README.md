# Bankist Website

A single-page banking landing page built as part of the Complete JavaScript Course. It showcases a modern marketing layout with smooth scrolling, section reveals, tabbed content, lazy-loaded images, a modal, and a testimonial slider.

## Project Description

Bankist is a polished, single-page marketing site for a fictional digital bank. The UI highlights key product features, operations, and customer testimonials while demonstrating core JavaScript-driven interactions.

## Features

- Sticky navigation with smooth scrolling
- Modal window for call-to-action
- Tabbed operations section
- Lazy-loading images
- Section reveal on scroll
- Testimonial slider with dots and keyboard support

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

Open the page directly or serve it with a local server.

### Option 1: Open the file

- Open [index.html](index.html) in your browser.

### Option 2: Live Server (VS Code)

- Right-click [index.html](index.html)
- Select **Open with Live Server**
