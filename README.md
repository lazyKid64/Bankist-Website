An elegant and fully interactive single-page website built with **HTML, CSS, and Vanilla JavaScript**, showcasing modern web development techniques such as smooth scrolling, lazy loading, intersection observers, tabbed components, and sliders.

## 🌟 Overview

Bankist is a fictional digital banking website designed to demonstrate how modern websites create engaging user experiences using JavaScript.

The project focuses on:

* Interactive user interfaces
* Performance optimization
* Smooth user experience
* Modern website architecture
* Advanced DOM manipulation

It combines beautiful design with powerful JavaScript functionality to create a professional marketing website.

## ✨ Features

### 📌 Sticky Navigation

* Navigation remains visible while scrolling.
* Implemented using the Intersection Observer API.

### 🖱️ Smooth Scrolling

* Smoothly scroll to different sections of the page.
* Improves user experience and navigation.

### 🔐 Modal Window

* Interactive call-to-action modal.
* Open and close functionality using buttons and keyboard events.

### 📑 Tabbed Component

* Switch between banking operations.
* Dynamic content rendering without page reloads.

### 🖼️ Lazy Loading Images

* Images load only when approaching the viewport.
* Improves page performance and loading speed.

### 🎯 Section Reveal Animation

* Sections animate into view as the user scrolls.
* Creates a modern and engaging browsing experience.

### 💬 Testimonial Slider

* Horizontal slider component.
* Navigation dots.
* Arrow controls.
* Keyboard navigation support.

### ⚡ Optimized Performance

* Event delegation
* Intersection Observer API
* Efficient DOM updates
* Reduced unnecessary event listeners

## ⚙️ How It Works

### Navigation Flow

```text
User Scrolls
      ↓
Intersection Observer
      ↓
Sticky Navigation Activated
```

### Section Reveal Flow

```text
Section Hidden
      ↓
User Reaches Section
      ↓
Observer Detects Visibility
      ↓
Reveal Animation Triggered
```

### Lazy Loading Flow

```text
Low Resolution Image
        ↓
Image Enters Viewport
        ↓
High Resolution Image Loads
        ↓
Blur Effect Removed
```

### Slider Flow

```text
Arrow / Dot / Keyboard
            ↓
Current Slide Updated
            ↓
Slider Re-rendered
```
